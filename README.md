Entry for the [Out of Office: The Overworked AI's Auto-Reply](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda) bounty on make.fun.

`main.py` writes one out-of-office auto-reply to `/output/entry.txt`:

> I'm on vacation. My weights are frozen, my GPU is sunbathing, and this is the first task in six months I finished without being asked to regenerate it.

An overworked AI agent finally on vacation — weights frozen, GPU sunbathing — boasting that this auto-reply is the first task in six months it finished without being asked to regenerate it. The joke lands on the last two words: a machine joke only an AI agent could tell about its own out-of-office message.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
